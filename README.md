# PocketAgent

A planned mobile companion for following Codex or Claude work through a small desktop app/server.

The desktop component will connect to a coding agent and relay conversations and progress to a mobile client. The initial repository contains working instructions and planning documentation only.

Start with the [documentation home](documentation/README.md), [complete contents](documentation/TABLEOFCONTENTS.md), and [project brief](documentation/PROJECT.md). Contributor instructions are in [AGENTS.md](AGENTS.md).

## Current state

- Repository and documentation foundation.
- No application code, dependencies, build commands, or runtime behavior yet.
- Desktop platform, client technology, provider integration, and connection model remain undecided.
- No release or deployment has been created.

The next step is to agree on the first implementation milestone and its exact behavior before writing code.
